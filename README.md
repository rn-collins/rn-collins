### About the repositories here

Most of what is public is a working build rather than a library. Each carries a README
stating what it establishes and what it does not.

The fifteen `nsag-m*` repositories are retired assessment modules, kept public as a
record; the current advisory work is in `nsag-site`. `rn-estate-tools` is the ship gate
every build has to pass — citation verification, dead-link and metadata checks, and a
written record of the ways the gate itself has been wrong.

Client engagements, private workspaces and credential-gated deployments are not here.
